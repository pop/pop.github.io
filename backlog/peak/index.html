Peak (2025)

published 2025-11-03 | tags: #backlog #games

Sam and I played peak pretty consistently every week for ~2 months and it's really fun!

I like that the game is somewhat random with the map resetting daily. Every time we played it was different, but we had the option to go back and try again with the same track.

The key feature is proximity chat, so if you are talking to your friend and they start to slip and fall you can hear them slowly fade away before they cut out. Priceless.

I'm excited to revisit this game every few months as they add fun additions and improve quality of life.
