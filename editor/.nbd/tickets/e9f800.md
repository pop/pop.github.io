## Goal

Make it immediately obvious at a glance whether a post is a folder-post or a
standalone `.md` file by appending a trailing `/` to the display name of directory
entries in the dashboard list.

Currently:
- Standalone files: `my-post.md`
- Folder-posts: **`my-post`** (bold, but no other visual marker)

Desired:
- Standalone files: `my-post.md`
- Folder-posts: **`my-post/`** (bold + trailing slash)

## Implementation

In `src/components/dashboard.rs`, in the `render_entry` function (~line 1696), the
entry name is rendered as:

```rust
<span class="entry-name">{&entry.name}</span>
```

Change it to conditionally append `/` for directory entries:

```rust
<span class="entry-name">
    { format!("{}{}", &entry.name, if is_dir { "/" } else { "" }) }
</span>
```

The `is_dir` boolean is already in scope at this render site.

No CSS changes needed — the bold weight on `.content-entry.is-dir .entry-name`
already applies to the trailing slash automatically.

## Verification

- Folder-posts in the dashboard list show a trailing `/` (e.g. `my-post/`).
- Standalone `.md` files continue to show their full filename with extension.
- Section-level directories (e.g. `blog/`, `fiction/`) also get the trailing slash,
  which is correct and consistent.
