The build and publish CI job (main.yml) currently fires on any push to the source branch, including changes to editor/ or .beads/ directories. It should only run when content/, templates/, or config.toml changes.

Relevant file: .github/workflows/main.yml (in parent repo root, not editor/)
Fix: Add paths-ignore or paths filter to the workflow's push trigger to skip editor/ and .beads/ directories.

Example fix:
on:
  push:
    branches: [source]
    paths:
      - 'content/**'
      - 'templates/**'
      - 'config.toml'
