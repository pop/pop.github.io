## Problem

The "Sync from source" button (`sync-btn`) is currently rendered in the editor toolbar
(`editor.rs` ~line 792). It belongs conceptually in the branch badge on the dashboard,
not buried in the editor page.

Additionally, `.sync-btn` has no CSS definition in `styles/main.css`, so the button
renders completely unstyled.

## Implementation

### 1. Remove sync button from editor toolbar (`src/components/editor.rs`)

Remove the `if auth.active_branch.is_some()` block that renders the `<button class="sync-btn">`.
Also remove the `syncing` state, `on_sync` callback, and any related logic that is
exclusively used by that button (the sync success/error message may stay or be relocated).

### 2. Add sync button to the active branch badge (`src/components/dashboard.rs`)

The active branch badge lives around line 1327 in `dashboard.rs`. It already has a
`.branch-badge-actions` div containing Publish and Discard buttons.

- Move the sync logic (merge `source` → editor branch) into the dashboard component.
- Add a `syncing` state and `on_sync` callback to dashboard.
- Render a "Sync from source" button inside `.branch-badge-actions`, only when
  `active_branch` is `Some`.
- Show "Syncing…" / "Sync from source" label as appropriate.
- Disable the button while syncing.

### 3. Style the sync button (`styles/main.css`)

Add `.sync-btn` CSS that matches the visual language of existing buttons.
A good choice is a neutral/secondary style (e.g. grey outlined, similar to a cancel
button) since syncing is a non-destructive utility action:

```css
.sync-btn {
  padding: 0.4rem 0.9rem;
  border: 1px solid #6a737d;
  border-radius: 4px;
  background: #fff;
  color: #24292e;
  font-size: 0.85rem;
  cursor: pointer;
}
.sync-btn:hover:not(:disabled) {
  background: #f3f4f6;
  border-color: #24292e;
}
.sync-btn:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}
```

## Verification

- Opening an editor with an active branch: no sync button visible in toolbar.
- Dashboard with active branch badge: "Sync from source" button visible in badge,
  styled consistently with Publish/Discard buttons.
- Clicking sync: button shows "Syncing…", branch is updated, success message shown.
