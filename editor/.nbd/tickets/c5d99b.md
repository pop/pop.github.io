## Problem

The Draft / Published status filter in the dashboard does not filter folder-posts
(directories that contain a single `index.md` file). The filter logic in
`dashboard.rs` (~line 1237) explicitly skips directory entries:

```rust
if cur_status_filter != StatusFilter::All
    && e.entry_type != "dir"   // ← always passes dirs through unchanged
    && e.name.ends_with(".md")
```

Folder-posts are directories (`entry_type == "dir"`) so they always pass the filter,
regardless of the selected Draft / Published setting. Ironically, the per-folder status
*is* correctly computed and stored in `folder_md_statuses`, and the icon displayed is
correct — the filter just never consults it.

## Implementation

In `dashboard.rs`, update the status filter block so that directories are filtered
using `folder_md_statuses` instead of being unconditionally passed through.

The logic should be:

```
if cur_status_filter != All {
    if entry is a .md file:
        check post_statuses[path] against filter
    else if entry is a dir AND folder_md_statuses contains an entry for it:
        check folder_md_statuses[path] against filter
    else:
        pass through (non-post dirs, non-.md files, media, etc.)
}
```

Concretely, around line 1237 replace the existing block with something like:

```rust
if cur_status_filter != StatusFilter::All {
    if e.name.ends_with(".md") {
        let status = post_statuses.get(&e.path);
        match cur_status_filter {
            StatusFilter::Draft => {
                if !matches!(status, Some(PostStatus::Draft)) { return false; }
            }
            StatusFilter::Published => {
                if !matches!(status, Some(PostStatus::Published)) { return false; }
            }
            StatusFilter::All => {}
        }
    } else if e.entry_type == "dir" {
        // Only filter if we have a known post status for this folder
        if let Some(status) = folder_md_statuses.get(&e.path) {
            match cur_status_filter {
                StatusFilter::Draft => {
                    if !matches!(status, PostStatus::Draft) { return false; }
                }
                StatusFilter::Published => {
                    if !matches!(status, PostStatus::Published) { return false; }
                }
                StatusFilter::All => {}
            }
        }
        // If no folder status (section dir, media dir, etc.) — pass through
    }
}
```

Note: `folder_md_statuses` is already in scope at the filter site as a `UseStateHandle`;
clone the inner `HashMap` reference to make the borrow work inside the closure.

## Verification

- Selecting "Draft" hides published folder-posts and shows only draft ones (🌱 icon).
- Selecting "Published" hides draft folder-posts and shows only published ones (📰 icon).
- Section-level directories (which have no entry in `folder_md_statuses`) always appear
  regardless of filter.
- Standalone `.md` file filtering continues to work as before.
