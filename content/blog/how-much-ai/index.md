This is a post about AI disclosure and where to draw the line. 

I have a personal policy of AI disclosure in everything I do. 
I like to disclosure if AI was used in a project and if so, in what capacity. 
The only time I omit this is if I didn't ship AI generated content. 

So AI generated code, even just a little: This uses some AI generated code. 
Mostly written by AI: This project was written by AI. 
Used in early shipped builds but not in the final product: Early versions of this project used AI generated assets/code.

I don't use AI for art, even placeholder art. 

Coders don't seem to care about AI code disclosure, maybe that's just my bubble.

I tend to use it for personal gamedev projects in two ways:
- Help me debug this, but don't fix it for me.
- I need to write a bunch of boilerplate, tedious, detailed code that I will get wrong if I do it by hand, but I know the shape of the solution.

for non-gamedev I have a loser hand:
- I have the idea and accept whatever it gives me that fits my criteria.

so what is this post about?
I was uploading a game to itch.io and it had an AI disclosure opt-in, which I like, but it forced me to consider "How much AI code is enough to say" Yeah, this contains AI generated code".
the game in question shipped with exactly one piece of AI generated code: building color pallets for Bevy UI.
