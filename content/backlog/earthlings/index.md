The first 5 chapters of Earthlings are pretty innocent compared to the final (6th) chapter.

Sure there is some sexual, and physical, violence, but its all like... understandable.

The main character is weird in a personable way that makes some valid points.
We've all had points in our lives where we felt like everybody was out to get us, we couldn't fit in, etc etc.
This character has that turned up to 11, but you still can at least empathize with her.
When life gets you down it's easy to escape the pain with some fantastical stories like "I'm actually an alien so it makes sense that nobody understands me."

Where this diverges is in the final chapter, which I think is why this was in Man Carrying Thing's "10 scary books" video because it is truly fucked up.
Not _the most_ fucked up book I've ever read, but certainly it makes the list.

I don't want to get into too much detail, because I still think the book is worth reading.
The final chapter is almost a... release.
A lot of pent up energy from the rest of the book, finally coming to it's extreme yet obvious conclusion.

Is it a fun read?
Yeah, it's a weird book and weird books are fun.

Would I suggest everybody read it?
No, but if you self identify as a weird book reader, you should check it out.
